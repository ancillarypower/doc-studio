# 印・章工廠 Doc Studio

騎縫章、浮水印、加頁碼、PDF 淨化與解密，**全部在你的瀏覽器內完成**，文件不會上傳任何伺服器。

Live: https://ancillarypower.github.io/doc-studio/ (after Pages is enabled)

Ported from the ClickUp artifact **印章工廠 v38** to Vite + React + TypeScript (strict) + Tailwind v4.

## Develop

```bash
pnpm install
pnpm dev            # http://localhost:5173
pnpm test           # unit + engine tests on the synthetic fixtures
pnpm build && pnpm build:reference && pnpm e2e   # smoke, axe and per-section visual diff
```

## Layout

| Path | What |
| --- | --- |
| `src/sections/` | one component per 區 (`data-section` = header, s1-upload … s10-log) |
| `src/studio/useStudio.ts` | all app state / effects / actions (lifted from the artifact's App), shared via `StudioContext` |
| `src/components/` | shared UI (DropZone, Diagram, ScanPanel, MethodThumb, SealThumb, LockedCard, YuxiFX, ui) |
| `src/pdf/`, `src/seal/` | PDF engine (parse, render, sanitize, encrypt/decrypt, post-process) and seal planning: untyped JS behind `.d.ts` boundaries |
| `fixtures/` | synthetic test PDFs, generated by `scripts/make-fixtures.mjs` (not committed; CI and `pnpm fixtures` create them) |
| `reference/` | the original artifact source + its build: the visual baseline (see `reference/README.md`) |

## Fixtures

- `fixtures/all-triggers.pdf`: trips all 12 categories of the 貳「檔案狀態」 scanner (metadata, old versions/orphans, JavaScript and auto-actions, attachments, links, PieceInfo/bookmarks, EXIF with GPS, annotations/forms, hidden layer, invisible text, signature field, same-colour/covered text).
- `fixtures/encrypted.pdf`: RC4-128, user password `test1234`, owner password `owner1234`.

Both are fully synthetic and deterministic. Create them with `pnpm fixtures` before `pnpm test` / `pnpm e2e`.

## Port notes (phase A: "make it identical")

Differences from the artifact, on purpose:

- Google Fonts `<link>` → self-hosted `@fontsource` (same families and weights).
- Tailwind 3.4 → 4.3: renamed `focus:outline-none` → `focus:outline-hidden`, `shadow-sm` → `shadow-xs`, `shadow` → `shadow-sm`; v3 defaults (border colour, placeholder colour, button cursor, ring) restored in `src/index.css`, along with the runtime's `#root` scroll container.
- React 18.2 → 19.2.
- The inline `<style>` block moved to `src/styles/app.css` (verbatim).

Kept as-is, to fix in phase B:

- Engine modules are still JS; values crossing the boundary are typed `EngineData` (`any`).
- `OptionPill` receives a `title` that it never renders (corner-preset tooltips never show).
- Metadata purge regenerates the document `/ID`, but the scanner treats any `/ID` as metadata, so 中繼資料 never reads clean after a purge.
- Low-contrast captions flagged by axe (inherited; the CI gate fails only on *new* critical/serious issues).
